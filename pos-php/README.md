# POS Production نسخة PHP (HTML/CSS/JS/PHP)

## المتطلبات
- PHP 8.1+
- SQLite مفعّل في PHP

## التشغيل محليًا
```bash
cd pos-php
php -S 127.0.0.1:8080 -t public
```

ثم افتح المتصفح على:
`http://127.0.0.1:8080`

## ما يتضمنه النموذج
- إدارة الفروع (الاسم، العنوان، الهاتف، التوصيل، العملة الأساسية الجنيه السوداني).
- إدارة المنتجات المرتبطة بكل فرع.
- إدارة المستخدمين والأدوار.
- تسجيل المبيعات وعرض ملخص حسب الفروع.

## ملاحظات إنتاجية
- يوصى باستخدام خادم ويب مثل Nginx أو Apache مع إعدادات أمان مناسبة.
- تفعيل النسخ الاحتياطي لقاعدة البيانات.
- إضافة طبقة مصادقة وصلاحيات متقدمة قبل الإطلاق.
